# API SPEC — SONORA

Base path: `/api/v1`

## Auth
- POST `/auth/register`
- POST `/auth/login`
- POST `/auth/logout`
- GET `/auth/me`
- DELETE `/auth/account`

## Catalog
- GET `/tracks/{track_id}`
- GET `/tracks/{track_id}/availability`
- GET `/artists/{artist_id}`
- GET `/albums/{album_id}`
- GET `/search?q=&type=&tags=&year_from=&year_to=&language=&country=`

## Feed
- GET `/feed?surface=for_you&cursor=&limit=`
- POST `/feed/events`
- POST `/feed/feedback`

Feed response includes canonical track, permitted preview state, artwork attribution,
provider links, tags, popularity class, and explanation string.
Never include a protected preview URL unless allowed for that user/territory/provider.

## Tags
- GET `/tags`
- GET `/tags/{slug}`
- GET `/tags/{slug}/tracks`
- GET `/tags/{slug}/related`

## Collections
- GET `/collections`
- POST `/collections`
- GET `/collections/{id}`
- PATCH `/collections/{id}`
- DELETE `/collections/{id}`
- POST `/collections/{id}/tracks`
- DELETE `/collections/{id}/tracks/{track_id}`

## User
- GET `/users/{username}`
- GET `/users/{username}/collections`
- POST `/users/{username}/follow`
- DELETE `/users/{username}/follow`
- GET `/me/music-dna`
- GET `/me/preferences`

## Integrations
- GET `/integrations`
- GET `/integrations/{provider}/connect`
- GET `/integrations/{provider}/callback`
- DELETE `/integrations/{provider}/disconnect`
- POST `/integrations/{provider}/playlists/add`

The playlist-add endpoint must return `unsupported` if no approved API capability exists.
Do not emulate private APIs or automate user passwords.

## Admin
- GET `/admin/catalog/duplicates`
- POST `/admin/catalog/merge-review`
- GET `/admin/previews`
- PATCH `/admin/previews/{id}`
- CRUD `/admin/tags`
- GET `/admin/reports`
- PATCH `/admin/reports/{id}`

## Common
- Cursor pagination.
- Consistent error envelope: `{code, message, request_id}`.
- Rate limiting.
- Input validation.
- Authorization per resource.
- OpenAPI generated by FastAPI.
